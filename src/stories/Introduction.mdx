# Tide design system

Tide is a small, token-driven React design system with form controls and layout primitives for building apps.

- **Colour.** The brand colour is a deep **teal**, with **coral** as a warm accent. **Slate** neutrals carry a slight blue-green tint so they sit well beside the teal. Every colour you use in an app is a *semantic* token (`--ds-color-primary`, `--ds-color-text-muted`, …), so light and dark themes switch automatically.
- **Type.** [Inter](https://rsms.me/inter/) for UI and body text (very readable at small sizes, with tabular numbers), [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) for headings, and [JetBrains Mono](https://www.jetbrains.com/lp/mono/) for code. All three are self-hosted variable fonts bundled through Fontsource.
- **Spacing.** A 4px grid (`--ds-space-1` = 4px … `--ds-space-16` = 64px). Controls come in three heights: 32, 40 and 48px.
- **Accessibility.** Every control is a native element underneath. Labels, hints and errors are wired up with `aria-describedby` / `aria-invalid`, and focus rings are always visible on keyboard focus.

Use the **Theme** toolbar button above to switch every story between light and dark.

## Using it in an app

```bash
npm install @aaronherbert/design-system
```

```tsx
import '@aaronherbert/design-system/fonts.css'; // Inter, Plus Jakarta Sans, JetBrains Mono
import '@aaronherbert/design-system/styles.css';
import { ThemeProvider, TextField, Button, Stack } from '@aaronherbert/design-system';

export function App() {
  return (
    <ThemeProvider theme="system">
      <Stack gap={4}>
        <TextField label="Email" type="email" />
        <Button>Continue</Button>
      </Stack>
    </ThemeProvider>
  );
}
```

## Token naming

- `--ds-color-*`: semantic colours. **Use these in apps.**
- `--ds-teal-*`, `--ds-coral-*`, `--ds-slate-*`: the raw palette. Prefer the semantic tokens.
- `--ds-space-*`: margins, padding and gaps
- `--ds-text-*`, `--ds-weight-*`, `--ds-font-*`: typography
- `--ds-radius-*`, `--ds-shadow-*`: shape and elevation
